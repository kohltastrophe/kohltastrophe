# Hi, I'm Kohl 👋

My development journey began in 2008 with a simple goal: figure out how MMORPGs worked so I could build my own. That obsession quickly led me down the rabbit hole of game modding, network protocols, and systems programming. Today, I design high-performance libraries and developer tooling built for minimal overhead and clean ergonomics.
